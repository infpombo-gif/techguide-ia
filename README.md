# 💻 TechGuide IA

Assistente virtual com Inteligência Artificial desenvolvido para auxiliar estudantes e iniciantes na área de tecnologia.

## 🎯 Objetivo

O TechGuide IA tem como objetivo responder dúvidas básicas sobre tecnologia e programação de maneira simples, clara e didática.

O projeto foi desenvolvido como parte do Lab **Construa Seu Assistente Virtual Com Inteligência Artificial**, da DIO.

## 👥 Público-alvo

* Estudantes de tecnologia;
* Pessoas iniciando na programação;
* Pessoas em transição de carreira para TI;
* Usuários que desejam revisar conceitos básicos.

## 🧠 Base de conhecimento

O assistente utiliza uma base de conhecimento contendo conceitos relacionados a:

* Python;
* Programação;
* Git e GitHub;
* Banco de dados;
* Fundamentos de tecnologia.

O assistente deve utilizar as informações disponíveis na base e evitar inventar informações quando não possuir dados suficientes.

## 🤖 Prompt do agente

O agente deve atuar como um tutor de tecnologia, utilizando linguagem simples e adequada para iniciantes.

Principais regras:

1. Responder de forma clara e objetiva.
2. Explicar termos técnicos quando necessário.
3. Utilizar exemplos simples.
4. Utilizar as informações disponíveis na base de conhecimento.
5. Não inventar informações.
6. Informar quando não houver dados suficientes para responder.
7. Evitar solicitar informações pessoais.

## ⚙️ Aplicação

A aplicação foi desenvolvida em Python e permite que o usuário faça perguntas ao assistente por meio de uma interface simples.

O protótipo demonstra o funcionamento básico de um assistente baseado em uma base de conhecimento organizada.

## 📊 Avaliação

Foram definidos os seguintes critérios para avaliar o assistente:

| Critério                            | Objetivo                                                              |
| ----------------------------------- | --------------------------------------------------------------------- |
| Clareza                             | Verificar se a resposta é fácil de compreender                        |
| Relevância                          | Verificar se responde à pergunta realizada                            |
| Confiabilidade                      | Evitar informações inventadas                                         |
| Base de conhecimento                | Verificar se a resposta possui fundamento nos dados disponíveis       |
| Tratamento de dúvidas desconhecidas | Verificar se o agente informa quando não possui informação suficiente |

## 🚀 Como executar

Tenha Python instalado e execute:

```bash
python app.py
```

Digite uma pergunta quando solicitado.
